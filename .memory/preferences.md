# Preferences

- Style, tone, and design choices for this project.

- [ui-analysis-batches] Les analyses UI se font par lots distincts avant toute refonte.

- [card-and-section-title-classes] Utiliser la classe de base .card et la classe .section-title au lieu de répéter des styles ou d'utiliser des attributs style="".

- [hover-and-focus-accessibility] Activer les effets hover/translateY uniquement sur les cartes cliquables avec @media (hover: hover) et :focus-within pour préserver l'expérience mobile et clavier.
