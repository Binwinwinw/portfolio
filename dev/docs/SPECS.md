# Registre préventif

Conserver les erreurs significatives, les corrections validées et les règles qui empêchent leur répétition. Ne pas utiliser ce fichier comme liste de tâches ou journal de session.

## Format d'entrée

```md
## Identifiant - Titre court

- Contexte :
- Erreur ou risque :
- Cause confirmée :
- Correction validée :
- Règle à appliquer :
- Fichiers concernés :
- Validation :
```

## Entrées

Aucune règle préventive issue d'une erreur confirmée pour le moment.
